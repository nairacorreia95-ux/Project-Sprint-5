# Project-Sprint-5
Project- Sprint 5
Dashboard de anúncios de carros
Descrição

Este projeto apresenta um aplicativo web desenvolvido com Streamlit para explorar um conjunto de dados de anúncios de venda de carros.

O aplicativo permite visualizar os dados de forma interativa por meio de gráficos.

Funcionalidades

O aplicativo oferece:

Um histograma para visualizar a distribuição da quilometragem dos veículos.
Um gráfico de dispersão para analisar a relação entre quilometragem e preço.
Gráficos interativos criados com Plotly Express.
Tecnologias utilizadas
Python
Pandas
Streamlit
Plotly Express
